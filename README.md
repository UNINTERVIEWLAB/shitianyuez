## Repository structure

Static HTML, CSS and JavaScript, published through GitHub Pages.

- `index.html`: personal introduction and featured projects
- `works.html`: project contributions, outputs and evidence
- `interview-lab.html` / `app.js`: interview practice interface and rule matching
- `growth.html`, `posts/`, `topics/`: professional learning archive
- `outside-work.html`: personal writing
- `assets/`: visual assets and presentation slides
- `style.css`: shared styles

To preview locally, run `python3 -m http.server 8000` from the repository root and open http://localhost:8000.
